## About

Algebra Studio helps teachers create tailored mathematics worksheets from a broad collection of topics and subtopics. Choose one topic or combine several in a mixed practice set, adjust the exercise settings, and review the result before sharing it with students.

The interface is in Hebrew and supports right-to-left layout, with editable mathematical expressions.

## Topics

The project covers six main groups with 24 subtopics, including:

- **Algebraic expressions** — opening parentheses, simplifying expressions, and algebraic identities.
- **Factoring** — common factors, trinomials, and quadratic expressions.
- **Equations and inequalities** — including systems of equations with two or three variables.
- **Powers and algebraic fractions** — practice with exponent rules and simplifying algebraic fractions.
- **Numbers, ratios, and percentages** — directed numbers, absolute value, ratios, percentages, and proportions.
- **Coordinate geometry, statistics, and probability** — including exercises with tables, charts, and tree diagrams.

## Worksheet builder

- Select one or more topics and combine them in a single worksheet.
- Choose the number of exercises, difficulty level, order, and exercise types.
- Customize exercise details such as variables, fractions, negative numbers, constants, and parentheses.
- Generate mixed practice sets with different kinds of questions.
- Edit an exercise or replace an individual question without rebuilding the entire worksheet.
- Add or edit exercise instructions and prompts.
- View full solutions and use projection mode to present questions and solutions in class.

## Student answer formats

Depending on the exercise, students can enter answers in different ways:

- Type a numerical or algebraic answer.
- Enter equivalent expressions.
- Complete a table or a probability tree diagram.
- Drag answers from a list into the appropriate places.

Some PDF exercises include answer choices and automatic feedback. Interactive feedback in PDF requires a JavaScript-capable PDF reader.

## Preview, save, and export

- Preview and refine the worksheet before distributing it.
- Save drafts in the browser.
- Export worksheets to Word with editable mathematical expressions.
- Print worksheets or export them as PDF.
- Create a standalone HTML worksheet that can be shared with students and used offline.
